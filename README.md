# Fortnite Chest Tracker

Публичный сайт для просмотра статистики открытых сундуков, собранной из локальных Fortnite replay-файлов.

## Что действительно работает

- поиск игрока по точному Epic nickname в опубликованной базе;
- импорт CSV, созданного ChestScan из replay-файлов;
- подсчёт сундуков и матчей за выбранный сезон/период;
- суммарная статистика по всем импортированным периодам;
- экспорт обновлённой базы в JSON;
- GitHub Pages deployment.

## Важное ограничение

Epic Games не предоставляет публичный endpoint, который по одному нику возвращает всю историю открытых сундуков. Поэтому поиск по нику работает только после импорта реальных replay-матчей. Нельзя восстановить матчи, для которых нет replay-файлов или ранее сохранённой статистики.

## Как получить реальные данные (Windows)

1. Скачай ChestScan из [релиза автора](https://github.com/Tanron009/fortnite-chest-scan/releases/tag/v1). Это сторонняя утилита, не созданная Epic Games и не написанная автором этого сайта.
2. Скопируй свои `.replay` файлы из `%LOCALAPPDATA%\\FortniteGame\\Saved\\Demos` в отдельную папку. Не работай с оригиналами.
3. Запусти `chestscan.exe "ПУТЬ_К_ПАПКЕ" --csv results.csv --name "ТВОЙ_EPIC_НИК"`. Если параметр `--name` не нужен, убери его. Утилита считает открытия сундуков, записанные в replay, и сама предупреждает, что точность проверялась ограниченно.
4. Открой сайт, укажи ник и название сезона/периода, выбери `results.csv` и нажми «Импортировать матчи».
5. Импорт хранится локально в текущем браузере. Нажми «Скачать базу игроков JSON».
6. Чтобы друг увидел эти данные на публичном сайте, замени файл `data/players.json` в этом репозитории скачанным JSON и отправь commit. После этого GitHub Actions обновит сайт.

## Что означают цифры

- «Всего» — сумма всех импортированных периодов, а не гарантированная статистика аккаунта за всю историю.
- «Последний импорт» — число сундуков в периоде, который только что импортировали.
- «Сезоны / периоды» — метки, которые ты вводишь при импорте. Разделяй CSV по сезонам, если хочешь сезонную статистику.
- Не импортируй один и тот же CSV повторно под другим названием, иначе матчи будут посчитаны дважды.

## Разработка

Это статический сайт без сервера и без сбора Epic credentials. Файл базы: `data/players.json`.
Для публикации: Repository → Settings → Pages → Source: GitHub Actions.
