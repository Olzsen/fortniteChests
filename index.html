Добавить свои матчи

Импорт CSV

1. Скачай ChestScan для Windows.
2. Скопируй replay-файлы из %LOCALAPPDATA%\FortniteGame\Saved\Demos в отдельную папку и запусти сканер с параметром --csv results.csv. Если нужно считать конкретный ник, используй --name "ТВОЙ_НИК".
3. Выбери CSV здесь. Укажи ник и название сезона/периода.

Импорт сначала сохраняется только в этом браузере. Чтобы статистика стала видна другу на сайте, скачай JSON и замени им файл data/players.json в GitHub-репозитории.
